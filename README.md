# Segundo Cérebro: Aprendendo Power BI com Inteligência Artificial

## Sobre o projeto

Este projeto tem como objetivo criar um assistente de estudos com inteligência artificial para aprender Power BI desde os conceitos básicos até a criação de relatórios e dashboards.

O assistente será desenvolvido utilizando o Gemini Notebook (NotebookLM), com fontes confiáveis, como documentações oficiais, artigos e vídeos educativos.

## Objetivos

- Aprender os fundamentos do Power BI.
- Compreender a transformação e a modelagem de dados.
- Estudar fórmulas e medidas DAX.
- Criar dashboards e relatórios interativos.
- Utilizar inteligência artificial para organizar os estudos.
- Gerar resumos, mapas mentais e questionários.
- Conferir as fontes utilizadas nas respostas da inteligência artificial.

## Tecnologias e ferramentas

- Power BI
- Gemini Notebook (NotebookLM)
- Inteligência Artificial
- GitHub
