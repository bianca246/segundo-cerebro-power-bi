# Testes do Segundo Cérebro — Power BI

Esta pasta registra os testes realizados no notebook de estudos, com o objetivo de verificar se as respostas são claras, úteis e apoiadas pelas fontes selecionadas.

## Teste 1 — Introdução ao Power BI

**Objetivo:** compreender o que é Power BI e conhecer suas aplicações práticas.

**Pergunta realizada:** Explique o que é Power BI para uma pessoa iniciante. Apresente três utilizações práticas da ferramenta e responda com base nas fontes adicionadas ao notebook.

**Verificação:** conferir se as informações estão corretas e se as citações correspondem às fontes originais.

## Teste 2 — Power BI Desktop, Power Query e DAX

**Objetivo:** compreender a função de cada recurso em uma análise de vendas.

**Pergunta realizada:** Explique a diferença entre Power BI Desktop, Power Query e DAX, usando um exemplo de análise de vendas.

**Verificação:** conferir as explicações, o exemplo e as referências citadas na resposta.

## Aprendizados

Os testes ajudam a organizar os estudos e a verificar as respostas do notebook com base nas fontes originais.
