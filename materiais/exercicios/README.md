# 🧠 Segundo Cérebro — Aprendendo Power BI

## Sobre o projeto

Este projeto foi desenvolvido como parte de um desafio de aprendizagem da DIO, com o objetivo de utilizar a inteligência artificial como apoio aos estudos.

O Segundo Cérebro utiliza um notebook de pesquisa com fontes selecionadas para organizar conhecimentos, responder perguntas, revisar conceitos e produzir materiais de estudo sobre Power BI.

## 🎯 Objetivos

- Compreender os fundamentos do Power BI.
- Estudar Power BI Desktop, Power Query e DAX.
- Aprender a consultar fontes e verificar citações.
- Criar materiais de estudo e exercícios.
- Registrar a evolução do aprendizado.

## 📂 Organização do repositório

- **materiais/** — guias, resumos e materiais de estudo.
- **exercicios/** — atividades práticas e acompanhamento do aprendizado.
- **testes/** — perguntas feitas ao notebook e registros de verificação das respostas.

## 📚 Fontes de estudo

- [Conceitos básicos de DAX — Microsoft Learn](https://learn.microsoft.com/pt-br/power-bi/transform-model/desktop-quickstart-learn-dax-basics)
